# Nagaraj Vatagal — Portfolio

Just open index.html in your browser — no install, no server needed.

## Project photos (now supports up to 3 per project, swipeable)

Each project has a small carousel — hover over the photo to see left/right
arrows, or click the dots below it to jump between photos.

projects/
  project1-1.jpg   project1-2.jpg   project1-3.jpg   <- AI Complaint System (up to 3 photos)
  project2-1.jpg   project2-2.jpg   project2-3.jpg   <- AI Data Viz Dashboard (up to 3 photos)

You don't need all 3 for each — if project1-2.jpg or project1-3.jpg is
missing, that slide is just skipped, no broken image shown.

Photos now use "contain" fitting instead of "cover" — meaning the WHOLE
screenshot shows without being cropped, even if it's a tall or full-page
screenshot. If there's empty space on the sides, that's normal for
non-square screenshots — it means nothing got cut off.

## Add your Vercel live demo links

Open index.html, search for "Live on Vercel" (there are 2, one per project).
Replace the href="#" right before each one with your real deployed URL.

## Adding a 4th photo to a project (optional, needs a small code edit)

If 3 photos per project isn't enough, tell me and I'll extend it — the
current version caps at 3 per project to keep things simple.
